# 5. Quick Reference — 운영자 의사결정 카드

## 분류 즉시 판단

```
이미지 1장 + 인물        → Type A → 보정도구 + Kling
이미지 1장 + 물건 + 효과  → Type C → 나노바나나 + Kling
이미지 2장 + 합성 의도    → Type B → 나노바나나 + Seedance
이미지 3장+  또는 스토리  → Type D → 나노바나나 + Seedance (장면별 병렬)
```

## Pre-eval FAIL 시

```
1회차: 실패 항목 수정 문구 추가 → 같은 도구로 재시도
2회차: 추가 수정 문구 강화 → 같은 도구로 재시도
3회차: 도구 전환
       경량도구 → 나노바나나
       나노바나나 → 경량도구 (과도 변형 시)
```

## Post-eval FAIL 시

```
1회차: 모션 프롬프트에 수정 문구 추가 → 같은 모델로 재시도
2회차: 수정 문구 강화 → 같은 모델로 재시도
3회차: 모델 전환
       Seedance → Kling
       Kling → Seedance
```

## 재시도 한도 초과 시

```
Pre 3회 + Post 3회 = 최대 6회 시도
초과 시: 최선 결과물 + 실패 로그 저장 → 수동 판단
```

## 절대 금지

```
✗ Controller와 Evaluator를 같은 대화창에서 운영
✗ 전체 프롬프트를 바꾸는 재시도 (실패 항목만 추가)
✗ 모션 프롬프트에 색감/조명/구도 반복 기술
✗ 평가 없이 결과물 납품
✗ 기록 없이 작업 완료
```

## 비용 빠른 계산

```
Type A: 보정(50원) + 평가(30원) + 영상(1,500~2,100원) + 평가(30원)
      ≈ 1,600~2,200원/건 (재시도 없을 때)

Type B: 나노바나나(50원) + 평가(30원) + 영상(1,500~2,100원) + 평가(30원)
      ≈ 1,600~2,200원/건

Type C: Type B와 동일

Type D: (이미지처리 + 평가 + 영상 + 평가) × 장면 수 + 스티칭 평가
      ≈ 1,700~2,300원 × N장 + 30원

재시도 1회당 추가: 이미지 도구(50원) + 평가(30원) 또는 영상(1,500~2,100원) + 평가(30원)
```
