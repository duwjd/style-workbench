# 평가 기준 상세

## 평가 공통 규칙

- 각 차원: 0.0 ~ 1.0 채점
- 0.7 미만 = FAIL
- 하나라도 FAIL = 전체 FAIL
- 관대한 평가 금지. "괜찮은 것 같다"는 판단 불가.
- 명확한 근거 없이 0.7 이상 부여 금지.


## Pre-eval 체크리스트

### 공통 (모든 유형)

| 항목 | PASS 기준 | FAIL 예시 |
|------|----------|----------|
| text_absence | 텍스트/워터마크/로고가 0개 | 구석에 작은 워터마크라도 있으면 FAIL |
| resolution_quality | 선명, 블러 없음, 노이즈 없음 | 확대 시 뭉개지는 영역 존재 |
| composition | 피사체가 의도한 위치에 배치 | 피사체 잘림, 극단적 편향 |

### Type A 추가

| 항목 | PASS 기준 | FAIL 예시 |
|------|----------|----------|
| face_natural | 얼굴 좌우 대칭, 눈/코/입 정상 | 눈 크기 불일치, 턱선 왜곡, 언캐니밸리 |
| skin_tone | 자연스러운 피부색, 과보정 없음 | 플라스틱 질감, 색 캐스트 |
| background_clean | 깔끔한 배경, 방해 요소 없음 | 잔상, 불필요한 물체 |

### Type B 추가

| 항목 | PASS 기준 | FAIL 예시 |
|------|----------|----------|
| identity_match | 원본 인물 얼굴 + 물건 디자인 정확히 보존 | 얼굴 변형, 물건 색상 변경 |
| scale_natural | 물건 크기가 인물 대비 현실적 | 시계가 팔목보다 큼 |
| lighting_match | 조명 방향/색온도 일치 | 인물은 좌측광, 물건은 상단광 |
| shadow_consistent | 그림자 방향 통일 | 인물 그림자 좌측, 물건 그림자 우측 |
| seam_clean | 합성 경계 불가시 | 헤일로, 색번짐, 경계선 보임 |

### Type C 추가

| 항목 | PASS 기준 | FAIL 예시 |
|------|----------|----------|
| object_preserved | 원본 물건 형태 100% 유지 | 녹아내림, 변형, 색상 변경 |
| effect_physics | 효과의 물리적 상호작용 자연스러움 | 불인데 그림자 없음, 물인데 굴절 없음 |
| effect_intensity | 과하지도 부족하지도 않음 | 물건이 효과에 묻혀 안 보임 / 효과가 미미 |

### Type D 추가

| 항목 | PASS 기준 | FAIL 예시 |
|------|----------|----------|
| scene_role | 장면이 스토리에서 의도된 역할 수행 | 도입 장면인데 클로즈업만 |
| color_tone | 다른 장면들과 색감 일관 | 혼자만 차가운 톤 |


## Post-eval 체크리스트

### 공통

| 항목 | PASS 기준 | FAIL 예시 |
|------|----------|----------|
| motion_artifact | 깜빡임/워핑/글리치 없음 | 중간 프레임에서 형태 일그러짐 |
| subject_preservation | 3프레임 모두 피사체 동일 | 마지막 프레임에서 형태 변화 |
| motion_compliance | 지시 모션만 수행 | 줌인 지시인데 패닝 발생 |
| speed_consistency | 균등한 이동량 | 갑자기 빨라지거나 멈춤 |

### Type A 추가

| 항목 | PASS 기준 | FAIL 예시 |
|------|----------|----------|
| face_consistency | 3프레임 모두 동일 인물 | 프레임 간 얼굴 변형 |

### Type B 추가

| 항목 | PASS 기준 | FAIL 예시 |
|------|----------|----------|
| composite_seam | 모션 중 합성 경계 불가시 | 카메라 이동 시 경계선 노출 |
| object_stability | 물건이 인물과 함께 자연스럽게 이동 | 물건이 떠다니거나 미끄러짐 |

### Type C 추가

| 항목 | PASS 기준 | FAIL 예시 |
|------|----------|----------|
| effect_continuity | 효과가 전 프레임 일관 | 효과 깜빡임, 갑자기 사라짐 |
| object_motion_integrity | 효과 속에서 물건 형태 유지 | 효과 때문에 물건 변형 |


## Cross-scene 체크리스트 (Type D 전용)

| 항목 | PASS 기준 | FAIL 예시 |
|------|----------|----------|
| color_consistency | 인접 장면 간 색온도 급변 없음 | 장면 2만 유독 차가운 톤 |
| brightness_consistency | 인접 장면 간 밝기 급변 없음 | 장면 3이 갑자기 어두움 |
| style_consistency | 시각 스타일 일관 | 일부만 일러스트 풍 |
| narrative_coherence | 시각적 흐름이 스토리 의도에 부합 | 순서가 뒤바뀐 느낌 |


## 도구/모델 전환 트리거

아래 조건 중 하나라도 충족 시, 같은 도구/모델 재시도를 중단하고 전환합니다:

### 이미지 도구 전환
- identity_match 2회 연속 FAIL
- seam_clean 2회 연속 FAIL
- 평가 근거에 "근본적 한계" 또는 "도구의 구조적 문제" 판단 시

### 영상 모델 전환
- motion_artifact 2회 연속 FAIL
- face_consistency 2회 연속 FAIL
- 같은 항목이 프롬프트 수정에도 개선되지 않을 때
